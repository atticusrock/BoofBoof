# Boof Boof 1.2.0

- Copy several files in Finder to save them as one entry. Restore the whole selection from the menu bar or Quick Switcher. Each group can hold up to 20 files and 100 MiB.
- Combine search with filters for text, links, images, files, and pinned entries. Search matches individual filenames in a group.
- Pause capture for 5, 15, or 60 minutes. The menu shows when capture will resume. Resume manually at any time.
- Boof Boof checks stored attachments before replacing clipboard contents. If a saved attachment is missing or damaged, the entry stays visible and the clipboard retains its contents.

Universal build (14) for Intel and Apple Silicon on macOS 13 or later. To update, quit Boof Boof, open the DMG, drag Boof Boof into Applications, and choose **Replace**. The app reads existing history and preferences. Group entries require version 1.2.0 or later.

This build uses an ad hoc signature. macOS Gatekeeper may show a warning on first launch because the build has no Apple notarization.
