# Boof Boof 1.0.4 (build 5)

- Improved link contrast in the light macOS appearance while keeping links readable in dark appearance.
- Removed the app and mail icons from About. About now shows only the app version and developer email; build number, date, and time are omitted.
- Universal macOS build for Intel (`x86_64`) and Apple Silicon (`arm64`).

Clipboard history remains local to this Mac. This build is ad-hoc signed and not notarized by Apple; macOS may show a security warning on first launch.
